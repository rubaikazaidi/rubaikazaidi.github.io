# Rubaika Zaidi portfolio

A static website. No build step, no dependencies.

## Files
- index.html, about.html, rifle-shooting.html, projects.html, certificates.html, initiatives.html, internships.html, contact.html, blog.html, 404.html
- style.css holds the whole design. The colours are in the :root block at the top.
- assets/ holds the resume, photos and certificate PDFs (see assets/README.txt).

## Fill in the placeholders
Everything in [square brackets] is a placeholder. In any editor, search for "[" to find them all.
Replace each "#" link (View certificate, GitHub buttons) with a real address or a file in assets/.

## Publish on GitHub Pages
1. Create a public repository named rubaikazaidi.github.io.
2. Upload all of these files, keeping the folders.
3. Settings, Pages: under Source choose "Deploy from a branch", then pick the main branch and the root folder.
4. Open https://rubaikazaidi.github.io after a few minutes.

## Use rubaikazaidi.info later (optional)
Add a file named CNAME containing only: rubaikazaidi.info, then follow GitHub's custom domain steps and change the DNS records at the domain registrar. Keep the old site live until the new one is ready.
